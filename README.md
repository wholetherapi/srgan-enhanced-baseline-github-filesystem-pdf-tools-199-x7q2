# Enhanced Super-Resolution Baseline

This repository implements the ESRGAN method:

"ESRGAN: Enhanced Super-Resolution Generative Adversarial Networks"

arXiv:1809.00219

It is inspired by the earlier SRGAN work (arXiv:1609.04802) but the implemented artifact is ESRGAN, with a different generator, discriminator and training objective. SRGAN is only referenced as background.
